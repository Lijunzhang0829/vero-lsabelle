## 新增机制

后续每次检查会自动保存提交前证明体和哈希、渲染源码、完整诊断、精确失败位置、候选检查结果；中断留下 submitted_no_result。运行结束或恢复后会归档记录，并将正式独立评估状态写入逐契约台账。没有诊断行的超时、前置目标阻塞、模块连带失败不会被误标成该契约数学失败。尚未送检的编辑不在记录范围内；agent 侧记录仅用于诊断，不能替代正式验证。

验证：20 项非内核测试通过，其中 6 项覆盖新机制；4 项真实 Isabelle 内核测试因本机未配置 VERO_TEST_ISABELLE 而跳过。本次没有重新执行模型生成。
