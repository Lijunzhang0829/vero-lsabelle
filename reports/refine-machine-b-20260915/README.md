## 已实现的代码

初版包含固定契约与正反证明槽位、合法前提检索、仓库级 Codex 代理、Isabelle 失败反馈、产物提取、全新工作区内核审计、时间预算和中断恢复。入口为 `python -m vero.isabelle` / `vero-isabelle`；使用方式见 [后端文档](../../docs/isabelle.md)。实现提交为 `6578916`，运行时源码内容标识保存在 [运行绑定](run-binding.json)。

这是 Isabelle 的独立 proof-mode 后端；尚未移植上游的全部代理适配器、codeproof、self 模式和分块会话续接。本次固定为独立 owner 模块，可复用同模块先前完成的事实，尚不支持跨 owner 导入生成证明。这是本版的重要限制。

## 输入与可信边界

直接复制并验证了本地相同的删除结果：287 个契约、21 个 owner、84,281 条合法前提，6,364 个文件逐一核对。没有给模型提供原始 Refine 人工证明、历史解答或目标 Refine heap。详情见 [实验协议](protocol.md)。

最终计分来自独立检查器对固定声明和提取出的证明体重新构建后的结果，并检查 `skip_proof`、oracle 和新增公理。代理的自行报告和 `oops` 预检都不算证明完成。完整轨迹中记录到 0 次协作代理调用，也未发现外部下载或读取认证文件的 shell 命令；见 [轨迹审计](trace-audit.json)。

17 项后端测试（包含真实 Isabelle 内核测试）和 31 项上游回归测试通过，见 [验证记录](validation.md)。
